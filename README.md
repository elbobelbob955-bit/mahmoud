# MECare

MECare is an Arabic-first iPhone medication reminder app with a simple elderly-friendly interface, local medication scheduling, reminder actions, and spoken Arabic reminder audio.

**Project identity:** ME visual system — dark interface with blue/cyan/violet accents.

**Author credit:** Engineer Mahmoud Ebid

## Build status

This repository includes a GitHub Actions workflow that compiles the app for the iOS Simulator on a hosted macOS runner without code signing.

Real-device installation and TestFlight/App Store distribution require Apple code signing and provisioning.
